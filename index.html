اتصل بقاعدة البيانات لعرض الأكواد.
تعليمات إعداد قاعدة البيانات (للمرة الأولى فقط)

تأكد أن جدول public.codes يحتوي الأعمدة: id و code و owner_name و created_at. إذا كانت سياسات القراءة أو الإضافة غير موجودة، افتح SQL Editor في Supabase وشغّل التالي. هذا يجعل الأكواد المعروضة عامة، فلا تضف معلومات شخصية أو سرية.

grant usage on schema public to anon;
grant select, insert on table public.codes to anon;

alter table public.codes enable row level security;

drop policy if exists "Public can read codes" on public.codes;
create policy "Public can read codes"
on public.codes for select
to anon
using (true);

drop policy if exists "Public can add codes" on public.codes;
create policy "Public can add codes"
on public.codes for insert
to anon
with check (
  length(trim(code)) between 1 and 80
);

لا تشغّل SQL إذا كنت غير متأكد من السياسات الحالية؛ ويمكننا مراجعتها أولًا حتى لا نكررها بلا داعٍ.
